# Привет, я Алина! 👋

### Дата-аналитик с глубокой экспертизой в FinTech

Я помогаю финансовым компаниям оптимизировать процессы, повышать эффективность и принимать решения на основе данных. 

Мой путь в аналитике начался с решения макроэкономических задач и привел к глубокому погружению в продуктовую и операционную аналитику.

### Ключевые компетенции:

*   **A/B-тестирование:** Разработка и анализ тестов для оптимизации коммуникаций и процессов
*   **Анализ воронок:** Построение воронок взыскания (от контакта до платежа) и поиск точек роста
*   **Анализ эффективности стратегий:** Оценка влияния новых инициатив на ключевые бизнес-показатели
*   **Операционная аналитика:** Оптимизация работы ключевых подразделений (колл-центр, отдел исполнительного производства), прогнозирование нагрузки и расчет штатной численности
